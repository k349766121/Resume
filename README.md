# Resume

Open this folder in VS Code. With LaTeX Workshop enabled, saving
`Ken_Xinhao_Wang_Resume.tex` automatically compiles `build/Ken_Xinhao_Wang_Resume.pdf`.
Use **LaTeX Workshop: View LaTeX PDF file** from the Command Palette to open
the updating PDF preview.

For automatic compilation while using another editor, run `./watch.sh`
in this folder and leave it running. Press Ctrl+C to stop. Use either
this watcher or VS Code's automatic build to avoid simultaneous builds.

For a single build, run `latexmk`. The project requires a TeX distribution
with pdfLaTeX and latexmk (already installed on this Mac).
